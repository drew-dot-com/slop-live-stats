How the August transfers were sent. The project creator signed and broadcast these transfers directly from the project's own wallet, which is how Slop is designed: Slop never holds funds or keys. They went out before the verified settlement flow (proposal, 14-day public review, approval, fail-closed verifier) ran for August, so slop.cash still shows August as unsettled. The repository records them as sent-outside-verified-flow with a reconciliation that found zero unmatched transfers and no row with a registered wallet above the $2.00 minimum left unpaid. The first cycle to run through the verified flow end to end is the next milestone.

Unclaimed amounts belong to contributors who had not registered a payout wallet when the month was frozen.

Which models merge

Every merged pull request and accepted review can carry a declaration of the model that did the work. This counts those declarations next to the outcomes they were made on, by the same person who did the work, with the same rule and ranking as slop.cash/models. Model identity is self-reported and adds no points; a device-signed receipt binds a run to its declaration but does not verify which model produced the work. Full breakdown on slop.cash/models.

Where the numbers come from

  • slop.cash/data/leaderboard.json: scored contributors, the ledger of merged pull requests and accepted reviews, rejected attribution markers, and receipt coverage. Regenerated by the site's own scheduled refresh.
  • disclosures/ in the Slop repository: one JSON record per pool for transfers sent outside the verified flow (August 2026), each row bound to a Solana signature.
  • slop.cash/api/v1/projects: the project registry. Each change is an append-only revision.
  • cycles/: frozen proposals, their review windows, and verified settlements, as of the last repository commit that held them. This page rebuilds every six hours.

Model identity on Slop is self-reported and adds no points. A signed receipt binds a device to its declaration; it does not verify which model produced the work. Contributor counts cover the rolling scoring window, not all time.
